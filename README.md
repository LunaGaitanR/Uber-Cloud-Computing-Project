# Uber Ride-Sharing System

This project consists of the analysis, design, and progressive development of a distributed system inspired by **Uber's ride-sharing platform**, developed for the **Cloud Computing** course at the Universidad Distrital Francisco José de Caldas.

The project is organized into four deliveries, progressively addressing the requirements, software architecture, cloud architecture, scalability, resilience, and implementation of the system.

---

## Deliveries

### Delivery 1 — Requirements & Workload Model

The first delivery focuses on the **requirements specification and workload modeling** of the proposed ride-sharing system.

This delivery establishes the functional and non-functional requirements, identifies the main actors and use cases, defines the system boundaries, and characterizes the expected workload under normal and peak operating conditions.

The workload analysis considers a large-scale scenario with **more than 100,000 simultaneous active rides**, establishing the basis for the architectural decisions that will be developed in the following deliveries.

**Deliverables:**

* Requirements specification.
* Workload model.
* System scope and boundaries.
* Actors and use cases.
* Functional and non-functional requirements.
* Supporting references.
